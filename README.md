# MECH5720: Sensors and Signals

## Useful commands
**Source workspace**
Run on each terminal instance to initialise the virtual environment.
This folder is not present in the repository, need to create manually following Lab 0 instructions.
```bash
source mtrx5720/bin/activate
```

**Find IP of devices on the network:**
Useful for finding what the IP address of the Raspberry Pi to connect to if the default values do not work.
This is also performed automatically when running `camview.sh`.
```bash
ip neigh
```
